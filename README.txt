วิธี deploy ขึ้น Vercel (ฟรี) — เลือกวิธีใดวิธีหนึ่ง

วิธีที่ 1: ลากวางผ่านเว็บ (ง่ายสุด ไม่ต้องลงโปรแกรม)
  1) แตกไฟล์ zip นี้ ได้โฟลเดอร์ vercel-pp5
  2) เข้า https://vercel.com ล็อกอิน แล้ว Add New > Project
  3) ถ้าไม่เห็นช่องลากวางไฟล์ ให้ใช้วิธีที่ 2 หรือ 3 แทน (Vercel เปลี่ยนหน้าเว็บบ่อย)

วิธีที่ 2: ผ่าน GitHub
  1) สร้าง repository ใหม่ใน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
  2) Vercel > Add New > Project > Import repository นั้น
  3) Framework Preset = Other, ไม่ต้องตั้งค่าอื่น กด Deploy

วิธีที่ 3: ผ่านคำสั่ง (ต้องมี Node.js)
  npm i -g vercel
  cd vercel-pp5
  vercel --prod

ติดตั้งเป็นแอปบนมือถือ
  Android (Chrome): เปิดลิงก์ > เมนู ⋮ > ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก
  iPhone (Safari): เปิดลิงก์ > ปุ่มแชร์ > เพิ่มลงในหน้าจอโฮม

ข้อควรรู้
  - เวอร์ชันบน Vercel เก็บข้อมูลในเบราว์เซอร์ของแต่ละเครื่อง (ไม่ซิงค์ข้ามเครื่อง)
    ให้กด "ดาวน์โหลด/สร้างข้อความสำรอง" ในหน้าตั้งค่าเป็นระยะ
  - ถ้าต้องการให้หลายเครื่อง/หลายคนใช้ข้อมูลชุดเดียวกัน ต้องต่อฐานข้อมูลเพิ่ม (เช่น Supabase, Vercel KV)
